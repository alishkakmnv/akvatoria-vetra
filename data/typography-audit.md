# Аудит типографики и читаемости — 17.07.2026

Метод: замер контраста скриптом в Playwright (WCAG-формула по computed styles,
эффективный фон вверх по дереву), desktop 1440 и mobile 375, обе темы.
Не «на глаз»: каждый текстовый узел страницы.

## Архитектура тем (сделано до правок)

Обе палитры вынесены в CSS-переменные `--t-*` в `globals.css`, переключение —
`data-theme` на `<html>` (кнопка в футере, localStorage, inline-скрипт против
вспышки). Tailwind-токены собраны через `@theme inline` → резолв в рантайме.
Тёмная закатная v1 сохранена как второй вариант для клиента: вода Three.js,
цветокоррекция фото и тень заголовка hero тоже тематизированы.

### Шкала и иерархия
- Тексты карточек (услуги, флот, шкиперы, фичи тарифов) подняты 14px → 16px:
  body не мельче 16, ступени caption 14 → body 16 → H3 20–24 → H2 36–56 → H1 48–92.
- Ключевые цифры укрупнены: цены в featured-карточках 16→18px semibold,
  в малых карточках 14→16px, стаж шкиперов 14→16px semibold. Цены тарифов
  и trust-цифры уже были display-кеглем (36/30px, амбер).
- Одна точка входа на секцию: H2 → цена/цифра акцентом → body. Оффер в hero
  переведён из серого в графит (вторая по силе точка после H1).
- Вертикальный ритм: H2 → контент mt-16 во всех секциях (без изменений, проверено).

### Микротипографика (lib/content.ts, скриптом)
- 237 неразрывных пробелов: разряды чисел («3 500 ₽»), число+единица
  («до 5 гостей», «6,1 м»), короткие предлоги/союзы перед словом.
- Тире длинные, кавычки «ёлочки» — были корректны, проверено.
- Смыслы и тексты не менялись — только подача.

## Контрольный замер после правок
- Desktop 1440, светлая: **0 нарушений** (мелкий <4.5, крупный <3, размер <14, opacity <0.75)
- Desktop 1440, тёмная: **0 нарушений**
- Mobile 375, светлая: 0 нарушений (trust 30px и цены 36px — large text, 3.5–3.7:1 при норме 3:1), горизонтального скролла нет
- Слоп-чек: прозрачность текста нигде не используется как «стиль», интерлиньяж
  body 1.5–1.65 (`leading-relaxed`), заголовки 1.05–1.2, строки ≤ ~65ch.
